A Claude skill · v1.2 · MIT

Thirty-two drafts. Eight in the bracket. One answer left standing.

When Claude's first answer isn't good enough, Colosseum gives the same task to dozens of sub-agents, each with its own strategy card. It keeps only the drafts that 3 independent reviewers rate highest. Those drafts then critique each other and revise, and 2 judges reading in opposite order score every match.

How a run works

Six stages, in order

Every sub-agent reads the same task file, word for word. Only the strategy card changes. The engine is one Python file using only the standard library. It keeps the whole run on disk, so a run can stop and pick up where it left off.

1

Draft

Each drafter answers with a different angle, method and priority.

32 calls
2

Screen

3 reviewers score each draft. Each reviewer's scores are standardised, and the top 8 go through.

18 calls
3

Critique

Rivals look for errors, gaps and inputs that break the answer, up to 8 points each.

14 calls
4

Revise

Each answer accepts a point and fixes it, or rejects it with evidence.

14 calls
5

Judge

2 judges read in swapped order. If they disagree, a third decides. The final always gets 3.

15 calls + tiebreaks
6

Merge

The top 3 are merged. The merge is kept only if both judges prefer it to the winner.

3 calls
Default run: 32 drafters → 8 → 4 → 2 → 1≈ 96 sub-agent calls, plus a tiebreak only when judges disagree

Accuracy · screening

A lenient reviewer can't push a weak draft through

Some reviewers score generously and some score harshly. A plain average rewards drafts that happened to land with a generous reviewer. Colosseum converts each reviewer's scores to z-scores first, so only the ranking inside each batch counts.

The setup on the right12 drafts with a known true order (D1 is best). 6 reviewers each score 6 drafts, so every draft gets 3 reviews. Half the reviewers add 40 points to everything.
What to look forSwitch between the two methods and see which 4 drafts reach the bracket. The same scenario is in the test suite as test_calibrated_ranking_beats_lenient_screener.

Cost · sub-agent calls per run

Same field size, a fraction of the calls

In a full knockout bracket, every drafter goes through critique, revision and judging. Colosseum screens first, so only the top 8 to 32 drafts do. That is where the expensive calls go.

Diversity · strategy cards

No two drafters think the same way

A card combines an angle, a method and a priority. Up to 169 drafters, cards come from an orthogonal Latin square, so any two drafters share at most one of the three parts.

16angles: Pre-mortem, Constraint map, Put numbers on it…
13methods: Checks first, Red-team pass, Verify every claim…
13priorities: Correctness, Evidence-backed, Scope discipline…
16 × 13 × 13 = 2,704 cards. Strategies that win more often are dealt more often in later runs, and every strategy still gets a turn.
Rows: angles · Columns: methods · Each cell sets a priority

Install

Two ways to run it

Claude Code

Copy the skill folder into your skills directory, then run /colosseum.

git clone https://github.com/adityaayushman/colosseum.git
cp -r colosseum/skills/colosseum ~/.claude/skills/

Claude Cowork

Save cowork/SKILL.md as a skill. The engine is embedded inside it and unpacks itself on first use, after a SHA-256 check. Nothing to download.

/colosseum --kind code --test-cmd "pytest -q" \
  --project /path/to/repo fix the flaky test
--quick12 drafters, top 4, ~40 calls
--full100 drafters, top 16, ~245 calls
--budgethaiku drafts, sonnet judges
--merge 0skip combining finalists
